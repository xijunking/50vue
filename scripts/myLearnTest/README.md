# myLearnTest 学习目录说明

这个目录主要用于整理前端复习资料和练习示例，按“方向文档 / 知识笔记 / 代码示例”三层来区分，后续新增内容也尽量按这个结构放。

## 目录结构

```text
myLearnTest/
├── README.md
├── notes/
├── roadmap/
└── examples/
```

## 各目录用途

### `notes`

放具体知识笔记，适合系统复习某一块内容。

例如：

- 前端知识总复习
- 某个主题的详细拆解
- 高频问题的总结

### `roadmap`

放复习方向、阶段计划、面试准备基调这类“导航型文档”。

例如：

- 面试复习路线图
- 阶段性复习计划
- 目标岗位分析

### `examples`

放可运行的小实验和练习代码，建议再按主题拆子目录。

例如：

- `event-loop`
- `promise`
- `state-management`
- `network`

## 当前整理后的建议使用方式

1. 先看 `roadmap`，明确当前阶段该复习什么
2. 再看 `notes`，系统理解对应知识点
3. 最后跑 `examples`，把抽象概念和代码行为对应起来

## 后续新增文件建议

为了避免目录再次变乱，后面可以尽量遵循下面的命名方式：

- 笔记类：`xxx-notes.md`
- 方向类：`xxx-roadmap.md`
- 示例类：用主题目录加简洁文件名

例如：

- `notes/js-core-notes.md`
- `roadmap/two-week-interview-roadmap.md`
- `examples/event-loop/basic-demo.js`
